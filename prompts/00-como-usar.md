# Como usar estes prompts

1. Preencha a ficha da solução (docs/ficha-da-solucao.md) antes de começar.
2. Abra o Claude Code na web (claude.ai/code) com o seu repositório selecionado.
3. Para cada entrega, abra uma sessão nova e cole o prompt inteiro.
4. Troque só o que está entre colchetes pelos dados do seu restaurante. O resto fica igual.
5. Leia o plano que o Claude mostrar. Se estiver certo, aprove. Se não, corrija no plano.
6. Espere terminar, teste no celular, siga para o próximo prompt.

Quebrou? Uma correção por mensagem, neste formato:
"Ao abrir a tela X, aparece este erro: [cole a mensagem inteira]. Corrija só isso."
Duas correções sem resolver: peça ajuda ao monitor.
